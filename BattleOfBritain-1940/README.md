# 1940 · 不列颠空战 — 战旗推演

复用 `InvasionOfPoland-1939` 的完整作战室引擎，在独立项目中展示1940年7月10日至10月31日的不列颠空战。原波兰目录保持不变；旧战役数据、配置与地图产物在 `archive/poland-1939/` 留存。

## 打开

```bash
npm run dev       # http://127.0.0.1:5193/
npm run build
npm run preview   # http://127.0.0.1:4193/
```

当前目录附带可运行的独立依赖副本和 `dist/`。首次在另一台机器运行可用 `npm ci` 安装锁定依赖；依赖版本沿用原项目。macOS也可双击 `start.command` 打开已构建的网页。通过HTTP打开，不能直接双击 `dist/index.html`。

## 内容

- 五阶段、十五个关键事件，使用简体中文并保留原文名称。
- RAF第10、11、12、13航空群；德国第2、3、5航空队。60个编制节点，其中27个代表飞行单位。
- 61次同日闭合出击、122条袭击／护航／拦截／返航航线；任务之间停留真实基地。
- 39个空战态势关键帧。袭击重点区与拦截区域可以重叠，固定RAF防区与雷达示意分层展示；空袭不表示领土占领。
- 454张离线地图瓦片、8192×10585投影画幅、真实高程与3D地形，覆盖英伦、法国至北纬44°、比荷、丹麦和挪威南部。沿用纸图、水面刻线、晕渲、字体、六角格与分级棋子。
- 保留原19种程序化模型，新增8种1940飞机：Spitfire、Hurricane、Bf109、Bf110、He111、Do17、Ju87、Ju88；均可在档案卡旋转查看并进入沙盘。
- 保留原90张照片，新增4张经许可核对的相关照片与离线参考地图；正文和照片图注区分事件记录与背景影像。
- 连续纯器乐背景、飞机与警报事件音效；原音效与音乐文件保留在素材库。英语节目在资料页提供官方外链，不默认播放波兰配乐或未取得再分发授权的历史录音。

## 操作

开场选择“自动推演”或“自由浏览”。滚轮缩放，拖动平移；点击时间轴事件、地图棋子或编制树打开档案。图例切换当前／完整航线、态势边界、RAF分区、雷达与地理图层；右上角可静音、分别调节背景音乐与音效音量、查看资料、全屏。

- `空格`：播放／暂停；`←`、`→`：上／下一重要事件。
- `,`、`.`：前后6小时；`H`：全战区；`M`：2D／3D；`Esc`：关闭面板或档案。
- 单位档案中的“镜头跟随”适用于2D与3D；3D左键旋转，右键平移。
- `?nointro`跳过开场；例如 `?nointro&t=1940-09-15T12:00` 跳到特定时刻。时间为英国当地BST钟面，不受设备当前时区影响。

## 校验与再生成

```bash
npm run verify                # 类型、单测、数据结构/引用/航速/素材、生产构建
npm run shots                 # 对正在4193端口的页面截图，需要本机Chrome
npm run shots -- --3d         # 包含3D截图
npm run debug:render -- --date 1940-09-15T12:00 --labels
bash scripts/geo/run_all.sh   # 使用原地图管线及缓存重建新战区
bash scripts/fonts/run.sh    # 原字体子集工具，增加配置与缺字读回检查
```

Python地图依赖见 `scripts/geo/README.md`；字体依赖见 `scripts/fonts/requirements.txt`。可通过 `PY=/path/to/python3` 指定具备依赖的Python。字体原文件、地图原数据与下载缓存位于本项目 `scripts/.cache/`，与波兰项目没有写入链接。

本作是来源可追溯的历史教学复盘。任务时刻、中间航迹、空域范围与代表编队数量是重建示意；未知确切小时的事件仅显示日期。兵力数字采用来源明确的统计口径，示意棋子数与历史总量分开。10月31日为英国官方战役期结束，后续夜袭仍继续。

场景配置：`config/scenario.json`；数据／代理接口：`docs/BRITAIN-CONTRACT.md`；素材署名与许可：`LICENSES.md`及网页资料页。

## 声音与镜头修复

默认背景为64秒连续纯器乐，不再循环无线电片段或叠加随机静电；背景音乐和事件音效分别调节，静音后恢复原播放进度。事件镜头按关联航线取景，2D与3D保持同一战区。点选事件会切换到对应日期并暂停；手动拖动、滚轮或全图操作取消旧导演运镜。

## 飞行方向与法国地形修复

事件飞机沿关联单位的完整出击、袭击／拦截与返航节点飞行。2D机头和3D模型均按地图投影后的航段方向旋转，编队间距随航向变化；阵营颜色由单位所属国家决定。时间跳转会立即清除旧编队、投弹与音效回调，护航和拦截战斗机不投弹。

导演播放越过事件时，驻留时间对齐该事件时刻，避免高速播放的日期超前导致简报、单位状态与演出错位；同一帧跨过的后续事件仍按顺序播放。

法国南侧地形由真实高程重新生成，补齐旧画幅8055像素以下的地图，矢量与全部瓦片使用相同范围。原投影与世界原点保持不变，已有机场、任务与地图坐标不受位移影响。素材验证及同坐标前后对比位于 `.work/a/verification.json` 和 `.work/a/france_source_comparison.png`。

此次修复通过98项单元测试及战役数据校验。Chrome复验8月8日与8月18日的实际Canvas绘制方向、9个3D出击／交战／返航／驻场时刻、法国旧边界上下的地形像素与离线加载；原有51项页面交互与四种屏幕尺寸检查也通过。脚本、截图和结果保存在 `.work/flight-france-fix/`。
