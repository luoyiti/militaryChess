# 1939 · 九月战役 —— 波兰战役战旗推演

复古作战室风格的 1939 年波兰战役（8/31 格莱维茨事件 → 10/6 科克投降）交互推演网页。

- **2D 作战地图**：离线自绘的泛黄纸质地图（真实高程晕渲 + 分层设色 + 水波纹海岸），叠加 1939 年国界、河流湖泊、森林沼泽和 18 km 六角格。
- **部队**：德国、斯洛伐克、波兰、苏联共 212 支部队（集团军 → 军 → 师/旅），用 APP-6 风格兵棋棋子表示，按缩放分三级显示并自动避让。
- **战线**：23 个关键帧控制区，通过有符号距离场（SDF）逐小时平滑插值，能正确表现包围圈的形成与消失、苏军入侵、德军后撤到分界线等过程。
- **推进**：62 条推进路线用彩铅锥形箭头随时间生长；另有 15 个包围圈（显示「被围第 N 天」）和德苏两条分界线。
- **时间轴与事件**：电报纸带样式的时间轴；62 个历史事件配打字机档案卡、90 张公有领域/CC 历史照片、音效和地图特效（炮火、斯图卡编队俯冲、爆炸）。
- **导演模式**：自动播放时遇到重要事件会暂停、运镜到事件地点、讲解，然后继续；配乐为肖邦《军队波兰舞曲》、《葬礼进行曲》和克拉科夫号角。
- **3D**：点击部队打开档案卡，可旋转查看 19 种程序化建模的「兵棋手办」（Pz.I–IV、35(t)、38(t)、7TP、TKS、T-26、BT-7 等）。另有 3D 沙盘模式：真实高程地形、占领区着色、发光战线和实例化部队。

## 运行

```bash
npm install          # 首次
npm run build        # 生成 dist/
npm run preview      # 打开 http://127.0.0.1:4188/
```

也可以双击 `start.command`（macOS），它会用 Python 静态服务器打开 `dist/`。

> 不能直接双击 `dist/index.html`：file:// 协议下浏览器会拦截数据加载。

URL 参数：`?nointro` 跳过开场，`?t=1939-09-17T12:00` 直接跳到指定时刻。

## 操作

| 操作 | 说明 |
|---|---|
| 滚轮 / 拖动 | 缩放 / 平移。放大后逐级展开到军级、师级 |
| 点击棋子 | 打开部队档案，含 3D 模型、装备、战史、相关事件；可「镜头跟随」 |
| 点击事件标记 / 时间轴圆点 | 打开事件档案卡 |
| `空格` | 播放 / 暂停 |
| `←` `→` | 上一个 / 下一个重要事件 |
| `,` `.` | 后退 / 前进 6 小时 |
| `H` | 回到全图 |
| `M` | 切换 2D 地图 / 3D 沙盘 |
| `Esc` | 关闭卡片 |

侧栏「图例」页可以开关各图层：占领区、战线、箭头、完整推进路线、包围圈、分界线、六角格、地形等。

## 数据校验与再生成

```bash
npm run typecheck                                  # 浏览器端与 Node 端类型检查
npm run test                                       # SDF 战线与 19 个模型的单元测试
npm run validate:data                              # 史实数据自检
npx tsx scripts/debug/render_debug.ts --date 1939-09-10T12:00   # 某时刻的调试图
node scripts/shots.mjs http://127.0.0.1:4188/ --3d # 多时刻截图冒烟（输出到 .work/shots/）
bash scripts/geo/run_all.sh                        # 重跑地图管线（DEM、瓦片、矢量、掩膜）
bash scripts/assets/run_all.sh                     # 重跑照片、音效、音乐、字体子集
```

`validate:data` 的检查项：
- 结构合规（zod）；坐标与地名引用都能解析，且在地图范围内；时间严格递增。
- 部队树：上下级梯队关系正确，没有环；各类引用都存在；每条数据都有来源。
- 战线关键帧：多边形不自交，德苏占领区不重叠。
- 合理性：行军速度不越界，部队不深入敌方控制区，战线推进方向合理。

## 说明与免责

- 本项目是**历史教学用示意推演**。国界、战线和部队位置依据公开史料整理，是近似和简化的结果。每条数据都标有来源和可信度，数字有分歧的地方给出区间；有争议的事件（如比得哥什 9/3 事件）已注明争议。
- 地图完全离线自绘，没有使用任何在线地图瓦片服务。范围仅限中东欧。
- 德军标识只用阵营色和铁十字，不出现卍字；含卍字的照片已人工排除。
- 3D 沙盘需要支持 WebGL2 的显卡。软件渲染（无 GPU）时帧率很低。

素材与数据许可见 `LICENSES.md`，页面右上角「资料」列出了全部来源。
