# 列宁格勒围城战 · 1941—1944

中文战役包 `leningrad-1941`。回放覆盖1941年6月22日至1944年1月31日：夏季战略前奏、陆上合围、解围作战与城市生存。正式围城从1941年9月8日计起；1943年1月18日突破封锁，1944年1月27日完全解围，首尾计入872天。

## 进入战役

```sh
npm run dev
```

打开 <http://127.0.0.1:5180/campaigns/leningrad-1941/>，也可从作战总台进入。生产构建后运行 `npm run preview`，地址为 <http://127.0.0.1:4180/campaigns/leningrad-1941/>。

九章包含北方推进、卢加阻击、合围城防、饥饿严冬、柳班、锡尼亚维诺、火花与铁路、走廊争夺和完全解围。地图提供北方战区、列宁格勒、拉多加与火花、沃尔霍夫—诺夫哥罗德四个镜头入口。代表性数据为88支部队、109个事件、48个控制关键帧、31条作战轴线、120个地名及14项装备。

## 阅读与操作

- **围城生活**随时间显示分类面包标准、运输阶段与市政状况。标准不代表实际领取量；早期没有本套粮卡记录时留空。
- **交通联系**默认随时间过滤。冰运、水运、铁路、油管各自判断，允许重叠。长短水路分别确定启用窗口；未核实的终期明确标为时效未确定。
- **全期对照**显示跨时期参考线路，不表示当前同时运行。图例中的交通总开关保留用户选择，跳时、换章和2D/3D切换不会重新打开它。
- **事件卡**保留80—140字正文，并可展开深入背景、来源定位和分歧。资料图标明其摄影日期；来源、作者、许可证与转换说明保存在照片索引和资料面板。
- **军事简报**按九阶段更新。棋子是代表性编制，父子单位不能相加作为总兵力；未经同口径核定的兵力和伤亡留空。
