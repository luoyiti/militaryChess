# 列宁格勒战役地理数据与再生

画幅覆盖东普鲁士—波罗的海—列宁格勒、完整拉多加湖与斯维里河，支持1941年夏战略前奏及1944年1月解围。它是历史教学地图；政治边界、实时接触线、旧界参考线和地名定位各有不同含义。

## 投影、精度与地图资产

- `config/geo.config.json` 是真源。范围 `[20,54,36,62.8]`；圆锥正形投影，标准纬线55°/61°，中央经线28°，中心纬度58.4°；画幅8192×7862。
- 四级纸质底图1024/2048/4096/8192像素，共340张WebP瓦片；总览2048×1966，3D反照率贴图4096×3931，高程图1024×983。
- 控制场网格820×787，每格约1.276公里，不能解释街区、单个工事或小于一格的桥头堡。火花行动必须依靠近景与有来源的控制关键帧阅读，不能靠放大把网格误差变成测量精度。
- 11处林区、7处沼泽根据地形与作战地理概括为近似轮廓，已明确标记`approx`；不是1941年植被或泥炭工业地籍调查。河湖采用Natural Earth物理地理，战后水库默认不画，伊尔门湖等天然水体保留。
- 通用Natural Earth陆地层不扣除独立内陆湖层。本战役额外清除拉多加、伊尔门等湖内的30,285个场网格，使湖区不再被当作可占领陆地或绘制陆地六角格。

## 政治边界与旧界

`pipeline/geo/borders_1941.py` 用海岸一致的Natural Earth现代国界重建**1941-06-22**政治底图：波罗的海三国归入苏联；加里宁格勒地区恢复东普鲁士、梅梅尔按1939年历史多边形恢复为德国；1940年苏芬和约后的维堡与拉多加卡累利阿归入苏联。汉科租借区为概略范围。该底图表示当时的实际政治地理，并不对兼并合法性作判断。

画幅内苏芬1940年线以现代芬俄线近似；画幅外的佩察莫、萨拉等差异不由本图表示。[1940年和约附图档案](https://nakanune.rusarchives.ru/en/node/214)与[1941年界线勘定报告](https://history.state.gov/historicaldocuments/frus1941v01/d38)用于时间与归属核对。边界细部仍有历史底图、现代岸线与制图简化造成的误差。

1939年地峡旧国界只作虚线参考，依据[芬兰测绘局战前卡累利阿地图](https://www.maanmittauslaitos.fi/en/e-services/karelian-maps)与旧地名走向概绘。它不参与掩膜，不等于1941年国界，也不等于1941年9月芬军止步线。主图实时控制以`data/fronts/`为准。

掩膜位：0苏联战区；1德国本土；2芬兰本土；4陆地；6其余陆地。湖区为0。德国、芬兰的推进分别使用独立控制槽；国界与占领区不得混为一层。

## 地名证据与重点纠错

地名输入与审阅记录保存在`pipeline/geo/gazetteer-*.json`。Nominatim查询是带范围约束的一次性研究输入，运行页面完全离线，不请求在线地图瓦片。查询结果必须按身份人工选择，不能自动取第一项：同名河流的几何中心、行政范围、铁路站和战毁旧村经常不同。

| 地点 | 本图定位 | 证据与限制 |
|---|---|---|
| 科博纳 | 31.55468E，60.02211N | OSM湖岸村；31.77275E是同名河流中心，不能作为港口。港区另有政府公布的纪念点。 |
| 科科列沃 / 奥西诺韦茨角 | 31.06410E，60.07454N / 31.08515E，60.11792N | OSM村落与海角对象，生命之路西岸参考，非逐季冰路测绘。 |
| 波利亚内 | 31.45545E，59.81691N | 铁路站；与沃伊博卡洛、同名村及草稿错误端点分开。 |
| 旧锡尼亚维诺村 | 31.11168E，59.83719N | 战毁村旧址；现代同名镇在北侧约8公里，不用于替代高地。 |
| 43.3 / 50.1高地 | 纪念地 / 旧村以南地区 | 43.3以纪念区定位；50.1仅依博物馆所述相对位置示意，`confidence: low`，未假称实测峰顶。 |
| 第1、第8工人村 | 地区代表点 | 坐标精度较低；不把纳济亚泥炭企业的同号现代聚落当作火花行动目标。第5工人村有政府公布的会师遗址GPS点。 |
| 奥列舍克要塞 | 31.03876E，59.95417N | 奥列霍维岛要塞博物馆范围点；与南岸什利谢利堡城及渡口分开。岛屿小于控制场网格。 |

基洛夫区政府的[战时遗址与纪念点名录](https://special.kirovsk-reg.ru/history/putevoditel_po_KMRLO/pamyatniki/_pamyatniki)用于旧村、港区、会师地点及铁路旧线的独立定位；本图没有把纪念碑点自动当成整个战时村界。[博物馆高地说明](https://dtdm.spb.ru/museum/qr0001.html)用于区分43.3与50.1。军、师与舰队代表标记仍是战役级示意位置。

[圣彼得堡历史博物馆的要塞说明](https://www.spbmuseum.ru/themuseum/news/56034/?lang_ui=en)明确奥列舍克位于奥列霍维岛，守军从1941年9月8日至1943年1月18日坚持守卫。其控制关键帧在德控多边形内扣除要塞洞；但小岛未被Natural Earth陆地格网解析，平滑距离场会受到南岸影响。不得以岛上接近零的场采样值推断要塞失守；应阅读守城事件与原始多边形洞，不人为扩大岛屿或涂改湖区陆地。

## 再生与验证

在仓库根目录执行：

```sh
sh campaigns/leningrad-1941/pipeline/geo/rebuild.sh
sh tools/py.sh campaigns/leningrad-1941/pipeline/geo/build_gazetteer.py
node tools/geo/emit_frame.mjs leningrad-1941 --check
npx vitest run campaigns/leningrad-1941/tests/geography.test.ts
npx tsx campaigns/leningrad-1941/pipeline/geo/sample_control.ts
```

重建脚本先运行共享地理生成器，再进行本战役湖区掩膜修正和图像/尺寸验证。原始Natural Earth和Terrarium数据位于共享缓存，下载工具可以补齐缓存；历史德国多边形与1939年德苏条约参考线已复制到本战役目录，重建不读取或修改其他战役。`geo/geography.meta.json`记录参数、位统计、逐点检查、输入哈希与来源。不要仅运行共享生成器后跳过湖区修正。

控制场独立采样覆盖前奏城市、季赫温反攻、火花走廊、43.3与50.1高地以及1944年1月终点。48个关键帧中的列宁格勒、奥拉宁鲍姆均应保持苏控；小岛另行输出精度提示，不作为格网可解析的地点断言。
