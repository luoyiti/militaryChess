# 列宁格勒围城战：中文研究档案

本轮核对日期：2026年10月18日。研究与回放范围为1941年6月22日至1944年1月31日，围城计时另从1941年9月8日开始。本文提供入口和证据使用规则，具体页码、档号与分歧保存在各专题和逐事件台账中。

## 专题与台账

| 档案 | 内容 |
|---|---|
| [军事研究](MILITARY-RESEARCH.md) | 十二个战略前奏节点，苏德芬作战、编制成立与重建、指挥交接、解围日期、地图边界及来源阅读范围。 |
| [城市生存研究](CIVILIAN-RESEARCH.md) | 分类配给、湖运与冰运重叠、铁路、撤离、市政、劳动与文化、死亡数字口径及逐张影像审计。 |
| [地理研究](GEOGRAPHY.md) | 1940年苏芬边界、1939年旧界、120个中文地名、战毁村与现代同名地物消歧、坐标置信度、再生流程与空间精度。 |

来源库位于 `data/sources/`。事件、部队、地图和装备均引用可解析ID；展开材料的来源也登记在所属事件的来源列表中。城市生活与军事展开材料分别位于 `data/ext/siege/notes.json` 和 `military-notes.json`。地名逐条保留原名、中文名、坐标、来源与置信度。

## 证据与精度

研究并用苏联档案目录与认证副本信息、德国原始文书的庭审转录、芬兰条约和军事研究、美国陆军战史、俄德拉脱维亚机构资料、市政行业史、个人日记与影像原页。机构展陈与战后战史按它们实际能够支持的内容使用，不自动视为战时原件。

台账的“高”表示可核实机构或原文明确支持事件日期及核心事实，不表示已核定每个团的位置或每小时战况。“中”表示连续过程使用代表日期、各来源边界有差异，或战术细节尚未完全独立互证。地理位置另按地名置信度判断；部队位置、作战轴线及控制多边形始终是近似重建，不继承事件日期的置信度。

仅书介、目录或搜索可见片段的材料明确标注阅读范围。书介只作进一步研究线索，不据以采纳具体死亡数；档案目录只用于可见的日期、标题、文种与档号，不替代未读的全文。没有准确页码的机构网页以专题标题及事件对应段落定位，不虚填页码。

除有证据的三个钟点节点外，军事事件均用日精度；民生事件全部用日精度。芬兰1941年7月10日当地15时换算为本战役莫斯科时间16时。日精度的00:00或12:00只服务时间轴排序，不能当作真实发生钟点。

## 关键解释边界

- 1943年1月18日打通狭窄走廊后，姆加与南侧阵地继续由德军控制；铁路仍遭炮击。突破封锁与完全解围分别呈现。
- 芬兰军队在不同地段的推进和停步不能概括成“从未越过1939年旧界”。芬军、德军控制槽独立；西班牙蓝色师团为德军序列中的志愿部队。
- 配给标准不代表实际领取或摄入。工人、职员、受供养者和儿童分列；125克不是全城所有人的统一标准。死亡估计按登记、地域、期间和疏散后死亡范围解释，不与军人伤亡混加。
- 冰运和水运有过渡重叠，铁路开通没有使湖运消失。1943年4月短航线的恢复不能外推为长航线的同日恢复；油管和电缆也不是同一工程。
- “火花”指令批准、第二突击集团军覆灭与重建、43.3/50.1高地、诺夫哥罗德战斗结束及二月才解放的城镇均保留独立节点与约束。
- “火花”参战初始兵力与1月12—30日全期军事减员采用有明确分类的统计表，完整范围见军事研究第八节；不能将不可恢复减员改称阵亡，也不能以跨至3月的1944年总战役损失代替一月数字。
- 照片原页的日期冲突照录；资料图注明摄影时间。39张库存照片均经审阅，只有适合对应叙述的8张附在事件卡，不将驳船运粮照称为冰道汽车车队。

仍值得进一步读取的材料包括油管及小航线报告原始扫描、晚1943年航运日志、冲突照片负片记录，以及可比较的粮卡、死亡和撤离登记。这些缺口在当前文案中保留，未用伪精确时刻、固定季节或插值曲线填补。
