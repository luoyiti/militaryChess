# 1940 · 挪威战役 —— 海陆空战旗推演

从 `InvasionOfPoland-1939/` 复制并适配的独立战役项目。原目录保持不动；运行时不引用原目录源文件、资产或依赖。

## 运行

推荐 Node.js 24 LTS（已在 24.19.0 验证）。

```bash
cd NorwegianCompaign-1940
npm ci
npm run dev
```

打开 http://127.0.0.1:5191/ 。生产版本：

```bash
npm run build
npm run preview
```

打开 http://127.0.0.1:4191/ 。`dist/` 包含完整离线地图、字体、照片、音效和 Worker，可独立部署到普通静态服务器。macOS 可双击 `start.command` 启动已构建的 `dist/`；若预览服务器已经运行，直接打开地址即可。不能通过 `file://` 直接打开。

## 内容与操作

- 1940-04-09 至 06-10，38 个历史事件、35 个代表性作战标记、37 条海陆空行动、18 个控制关键帧、50 个地理锚点、21 条来源。
- 德国、挪威、英国、法国、波兰五国棋子；登陆、舰艇行动、航空、陆路推进、撤退/撤运分别用线型和符号区分。
- 全国战略、奥斯陆/南部、中部、纳尔维克、海上战场切换；滚轮缩放、拖动平移。
- 0.5 / 1 / 2 / 4 / 8×，暂停、拖动时间轴、指定日期、全部事件索引；导演模式自动聚焦、驻留并显示档案。
- 部队搜索与档案、原版符号和 3D 手办查看器；Three.js 沙盘显示同源挪威地形、部队、控制色与行动丝带。
- 原版 howler 音效与 Web Audio 合成兜底。3 张公共领域历史照片。可选原创英语摘要由浏览器语音合成；非历史录音，语音取决于系统。原波兰号角与配乐未用于挪威战役。

快捷键：空格播放/暂停；← → 前后重要事件；`,` `.` 前后 6 小时；H 全国；M 2D/3D；Esc 关闭档案。手机默认折叠侧栏，左侧箭头可展开；档案打开后镜头将目标放到上方可见地图。

## 实际复用

保留 TypeScript/Vite、D3 Canvas/SVG 瓦片与缩放、APP-6 棋子和避让、`model/core` 轨迹、SDF 距离场及 Worker、路线进度/箭头、store/clock、导演、时间轴、档案/序列/图例、字体和作战室 CSS、音频管理、Three.js 模型/查看器/沙盘、Python 地理渲染管线。没有另起地图、时间轴或动画引擎。

扩展：1940 日历与 NO/UK/FR，海空撤运路线类型，登陆/易手 step 状态（山谷范围仍可插值），国家标签和机场/港口图标，战区视角、事件索引/日期跳转、并行态势、手机布局、可选英语合成朗读、海空符号模型。只在新副本修复了侧栏裁剪、空 SVG 航线、主动选事件未 seek、时间回拖旧卡片/导演驻留等问题。

实施计划与原代码审计：`docs/IMPLEMENTATION_PLAN.md`。历史编排核对：`research/HISTORY.md`。来源在每个事件和「资料」中可查；逐项素材许可见 `LICENSES.md` / `public/credits.json`。

## 验证与再生成

```bash
npm run verify       # typecheck + 52 tests + schema/reference/date/geometry validation + production build
npm run shots        # 生产预览运行后：实际 Chromium 操作、全部事件、3D、桌面和手机截图
npm run frame        # 唯一投影参数
npm run geo          # 已有原始数据缓存时重新生成挪威地图（Python需numpy/scipy/shapely/Pillow/requests）
npm run data         # 重新生成史料数据，保留已下载照片关联
```

本机自动化优先使用 Playwright 对应的已安装 Chromium；缺失时可使用现有 macOS Google Chrome。也可通过 `PLAYWRIGHT_EXECUTABLE_PATH` 指定浏览器。测试证据保存在 `.work/shots/verification.json` 与截图中，最终验证摘要见 `docs/VERIFICATION.md`。

地理生成直接复用原有的 `LL → D3 XY → TopoJSON → DEM/纸纹/瓦片/掩膜` 流程。新的入口为 `scripts/geo/run_all.sh`；旧的波兰专用地理准备脚本不用于新战役。运行不依赖这些缓存，只依赖已随项目提供的 `public/`。

## 解释范围

这是历史教学推演，不能当作逐小时战场测绘或完整兵力表。单位代表性部署、分遣队聚合和端点间插值均有简化；不确定时分仅为播放排序，事件显示“当日”。控制区只表示主要据点与交通走廊，6月10日的全境占领由态势文字说明，不伪造精确行政占领边界。

Natural Earth 1:10m 海岸线为概化地理，Mapzen z6 高程约公里级；峡湾细节不是航海图精度。挪威/瑞典陆界适用于本战区；其他周边现代国界用于定位，芬兰/苏联1940年边界变化未复原。35个标记不等于全部参战编制；兵力与损失口径未统一，因此没有将未核实数字填入比较图。

3D需要WebGL；检测到软件渲染会降低分辨率与地形网格、关闭阴影，仍可能比2D慢。海空/盟军步兵模型是符号棋子，不声称还原实际舰型、机型或各国制服。语音缺失时可阅读英语摘要，基础地图与时间轴不受影响。
