# 淞沪会战（shanghai-1937）

中文战役包，采用1937年8月13日至11月12日上海华界失守的狭义会战范围。涵盖市区争夺、沿江登陆与北郊激战、蕰藻浜与大场、苏州河与四行、杭州湾登陆与西撤五个阶段；不包含1932年战事、11月中下旬苏锡追击及南京阶段。

## 内容

- 30个代表性编制与标记，含双方指挥节点、师／师团、宝山营、四行守备分队及海军存在示意；不是全量战斗序列，不能重复加总军、师和分队人数。
- 25个中文事件、37个地名、13个控制关键帧、12条陆上／海运方向、6张装备说明卡。
- 2D纸质地图、3D地形、中文章节、导演推演、总台卷宗、3张已核来源与许可的本地照片。
- 完整地图资产：84张分级纸图瓦片、矢量水系、场掩膜、3D地形贴图及高度图。

## 资产复现

地图必须使用战役专属包装脚本。它在共享矢量步骤后补入黄浦江、苏州河、蕰藻浜与外国守备核心，并让纸图、3D和掩膜使用一致几何。直接运行通用 `tools/geo/run.sh` 会遗漏这些补图步骤。

```bash
sh campaigns/shanghai-1937/pipeline/geo/run.sh
# 投影和范围未变、已有投影DEM时可复用：
sh campaigns/shanghai-1937/pipeline/geo/run.sh --skip-dem

GEO_CAMPAIGN=shanghai-1937 sh tools/py.sh campaigns/shanghai-1937/pipeline/geo/verify.py
node tools/geo/emit_frame.mjs shanghai-1937 --check

# 重新核取Commons文件元数据、许可模板和原图，生成照片及证据索引：
sh tools/py.sh campaigns/shanghai-1937/pipeline/fetch_photos.py
npm run fonts
```

首次地图构建会联网获取缺少的开源底图与高程缓存；照片脚本也需要网络。正常运行使用已生成的本地地图与照片资产。

## 验证

```bash
npm run typecheck
npm test -- campaigns/shanghai-1937/tests --no-file-parallelism
npm run validate -- --campaign shanghai-1937
npm run verify
```

`tests/campaign.test.ts` 检查清单、数据引用、中文篇幅、编制和资源；`tests/history.test.ts` 独立核查历史约束，直接调用生产单位状态及SDF，读取交付掩膜，验证登陆前不可见、登陆当日跳变、宝山控制时序、四行羁留终态及外国守备核心排除等，不能以原始多边形包含关系代替实际着色结果。

数据校验保留一项已复核速度警告：四行分队由守仓哨点切换至租界羁留地域时，通用校验器按最低1小时折算为70公里／天，超过 `fortress` 的30公里／天阈值。这是日级状态切换，不是实测行军速度；不伪加铁路／海运、不改变兵种或放宽阈值来消除提示。

## 研究证据与取舍

- `data/sources/main.json`：界面可点击的史料目录。
- `pipeline/research.json`：逐项实际阅读范围、来源权重、时间线、编制、海空行动、平民与租界、数字口径、争议和未取得的资料。FRUS两份同期电报读到全文；JACAR杭州湾登陆资料仅读到目录与内容摘要，不冒充扫描原件。
- `pipeline/photo-evidence.json`：三张采用照片的Commons元数据、许可模板与使用边界；排除错期的“杭州湾登陆”候选及1945年新不列颠获释人员照片。
- `pipeline/geo/evidence.json`：地图数据、地名定位、近似河道、掩膜与地形的生成依据及局限。
- `public/campaigns/shanghai-1937/credits.json`：照片、声音、字体与地理署名；主要限制也在界面“资料”与图例中公开。

主要史实处理：宝山营采用9月7日而非误抄的9月5日；四行为524团第一营等约四百余人，谢晋元为中校团附、杨瑞符为营长，撤入租界后为羁留而非向日军投降。四行撤离的10月31日凌晨／31日夜至11月1日凌晨两种记述均保留。上海派遣军与第10军原先平级，11月7日华中方面军成立后才同受统辖。第10军成立与11月5日登陆分开；11月13日才登陆的第16师团不进入本卷。

## 精度边界

- 09:00播放起点、日级切换的午夜／正午以及前一分钟哨点都是显示契约，不是新考证出的历史钟点。部队位置证据结束后的淡出，不代表部队覆灭或停止作战。
- 控制场与轨迹只表达作战地域概势。1938政治底图不用于判定1937占领；11月12日华界失守不等于公共租界、法租界同日整体被日军占领。
- 外国守备核心是保守内区示意，不是完整租界边界，也不是免于炮击的安全区。四行建筑用分队和孤立点表达，不放大成虚构的大块控制洞。
- Natural Earth海岸与现代高程不是1937岸线。城市河段按地标近似连线，未取得完整OSM水系或可配准的历史精细岸图。北川沙／狮子林地名锚点保留，作战标记另用邻近陆上示意点，不能反推精确登陆滩头。
- 累计投入与同日在场兵力、军人伤亡与平民受难、上海与后续南京阶段分别处理；缺少同口径可复查数字时保留空缺。通用步兵、舰船与飞机模型也不是1937具体制服或型号复原。
