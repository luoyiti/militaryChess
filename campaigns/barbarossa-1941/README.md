# 巴巴罗萨行动（barbarossa-1941）

1941 年 6 月 22 日凌晨德军越境，到 12 月 5 日红军在莫斯科城下转入反攻。北起芬兰、南到克里米亚和亚速海，按小时重现轴心国六方（德、芬、罗、匈、斯洛伐克、意）与苏军的推进、包围圈与战线。

| 内容 | 数量 |
|---|---|
| 部队 | 444（德 157 · 苏 231 · 芬 22 · 罗 17 · 匈 7 · 斯洛伐克 6 · 意 4），集团军群/方面军 → 集团军 → 军 → 师 |
| 战线关键帧 | 51（德方占领区 + 芬兰占领区两套，`data/fronts/`） |
| 包围圈 | 26（比亚韦斯托克—明斯克、乌曼、基辅、维亚济马—布良斯克、敖德萨、塞瓦斯托波尔、汉科等） |
| 路线 | 112 · 筑垒地域与防线 32（斯大林防线、卢加防线、莫扎伊斯克防线等，`data/overlays.json`） |
| 事件 | 154（重要度 1/2/3：21/83/50），59 条配历史照片 |
| 地名 / 来源 / 装备 / 照片 | 406 / 207 / 34 / 97 |

时间为柏林时间（中欧夏令时），莫斯科时间 = 柏林时间 + 1 小时。

## 目录

- `campaign.json`：阵营、阶段（边境交战 / 斯摩棱斯克与乌曼 / 基辅与列宁格勒 / 台风行动 / 兵临莫斯科）、简报、图例、导演、总台卷宗。
- `config/geo.config.json`：取景（斜轴圆锥，旋转 −31°）、1941 年 6 月 22 日国界（`pipeline/geo/borders_1941.py`：1938 年底图 + 1939 年德苏分界 + 梅梅尔、比萨拉比亚、汉科租借地）、掩膜比特（0 苏联，1 德国，2 罗匈斯，3 芬兰）。
- `data/`：分区文件按「北方 / 中央 / 南方」与参战方拆分（`oob/north_de.json`、`oob/ro.json` …），**全部由 `pipeline/` 里的脚本生成，不要手改**。
- `docs/research/`：各分区的研究笔记、取舍与已知简化（`BRIEF.md` 是给各分区代理的约定）。
- `campaign.css`：筑垒地域的点线样式。

## 重新生成数据

```bash
sh campaigns/barbarossa-1941/pipeline/build_all.sh
```

顺序：核心地名 → 战线关键帧、包围圈、防线（`pipeline/fronts/`）→ 中央、南方、北方各分区（北方部队轨迹按关键帧校正）→ 装备、兵力与战略事件（`pipeline/scripts/assets/`）→ 整合补丁（`pipeline/build/lead_patches.py`：补齐过早结束的轨迹、登场时刻、包围圈内部队、分阶段兵力并入各方说明）→ 合并事件与配图 → 校验。不联网，可重复运行。

照片另行下载：`python3 pipeline/scripts/assets/fetch_photos.py`（Wikimedia Commons，写入 `public/campaigns/barbarossa-1941/photos/` 与署名）。地图资产：`sh tools/geo/run.sh barbarossa-1941`。

## 检查

```bash
npx vitest run campaigns/barbarossa-1941
npx tsx campaigns/barbarossa-1941/pipeline/build/check_positions.ts --km 50
```

测试用浏览器同款 SDF 控制区场核对 32 座城市的陷落时刻、罗斯托夫的失而复得、莫斯科/列宁格勒/图拉/塞瓦斯托波尔守住，以及包围圈存续期间锚点被占领区围住。位置检查逐日比对部队与控制区：阈值 50 km 时只剩 9 支部队在突围或交接的一两天里越线（如 7 月第 44 步兵军、10 月博尔金集群），属于关键帧间线性插值的固有误差。

## 已知简化

- 控制区是关键帧之间的线性插值，快速合围（如 9 月 14–16 日基辅包围圈闭合）在两帧之间会显得偏慢。
- 苏军师级单位只收录在主要包围圈与关键防御战中出现的番号；大量预备队师、民兵师合并在集团军指挥部的说明里。
- 兵力与损失数字各来源口径差异很大（克里沃舍耶夫、德军陆军卫生报告、哈尔德日记），简报列常见区间，分阶段数字在各方说明里。
- 汉科半岛、奥拉宁鲍姆桥头堡、塞瓦斯托波尔等小块苏方控制区用包围圈「洞」表示；喀琅施塔得所在的科特林岛小于控制区网格，不单独显示。
