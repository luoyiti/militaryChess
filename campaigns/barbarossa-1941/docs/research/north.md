## 2. 年表（已核对部分）
### 边境交战（6.22–7.9）
- 6.22 拂晓：XLI 军自蒂尔西特—陶罗根方向、LVI 军自蒂尔西特以南攻入立陶宛；LVI 军当日夺阿里奥加拉杜比萨河公路高架桥，前出 60–70 km。
- 6.23–6.27 拉塞尼艾坦克战：苏 3 MK 2 TD（索良金）与 12 MK（23、28 TD）反击 XLI 军；6 PzD 塞肯多夫战斗群在斯考德维莱被 2 TD 冲垮；单辆 KV（一说 KV-2）在杜比萨河桥头堡后方公路上阻滞劳斯战斗群约 1 天，6.25 晨被 88 炮与工兵击毁。6.26 前 1 PzD、36 ID(mot) 合围 2 TD，索良金阵亡。苏方坦克损失约 700 辆（Glantz）。23 TD 6.23 在希奥利艾西南遭空袭，约 40 辆车起火。
- 6.24：LVI 军进至乌克梅尔格；II 军进入考纳斯。
- 6.25：苏方决定撤至德维纳河；27 A、21 MK、5 空降军调往德维纳河。
- 6.26：8 PzD（勃兰登堡部队协助）夺取陶格夫匹尔斯德维纳河大桥；桥头堡战斗至 6.29，苏 21 MK 6.28 反击未果。
- 6.29：XLI 军在克鲁斯特皮尔斯/叶卡布皮尔斯渡德维纳河；291 ID 占领利耶帕亚（6.23–6.29 守城：67 SD 与海军基地）。
- 6.30：德军抵里加道加瓦河；库兹涅佐夫因下令后撤被撤职，索边尼科夫接任。
- 7.2：XLI 军在 8 A 与 27 A 结合部突击；7.3 占古尔贝内，8 A 退入爱沙尼亚，西北方面军被一分为二。
- 7.4：LVI 军占列泽克内后转向奥斯特罗夫；1 PzD 当日夺奥斯特罗夫维利卡亚河桥。7.5 苏 111 SD 与 3 TD 反击一度收复；7.6 德军再入城。
- 7.7–7.9：41 SK 退向普斯科夫；7.8 普斯科夫西半部失守；7.9 XLI 军占普斯科夫；LVI 军（8 PzD）在普希金山区渡维利卡亚河。7.8 217 ID 占派尔努。

### 列宁格勒接近地（7.10–9.30）
- 7.13 8 PzD 占索利齐；7.14–7.18 苏 11 A 索利齐反击，8 PzD 一度被围，经 SS-T 接应突出，放弃索利齐；LVI 军停顿。7.22 I 军重新夺回索利齐。
- 7.14 6 PzD 第 113 摩步团 1 营在伊万诺夫斯科耶夺卢加河桥头；7.15 1 PzD 在大萨布斯克夺桥头。此后 XLI 军在桥头堡停留约三周。
- 7.17–7.19 58 ID、36 ID(mot) 在格多夫附近围歼 118 SD 一部；269 ID 在普柳萨河。7.19 I 军占德诺。
- 爱沙尼亚：7.22 德军在派德—蒂里结合部突破，8 A 被割裂；11 SK 在楚德湖岸被歼（德方称俘 8794 人）。8.4 占塔帕，8.7 抵孔达海岸，塔林被隔断。8.17 纳尔瓦失守（291 ID 自西、58 ID 自南）。8.28 217 ID 占塔林（德方称俘 11432 人）。XLII 军部负责塔林作战。
- 8.8 XLI 军自卢加桥头堡发起总攻（1、6 PzD、1 ID、36 ID(mot)），8.9 1 PzD 突破并与 6 PzD 会合；8.14 切断红卫城—金吉谢普铁路；8.16 占沃洛索沃；8.17 金吉谢普失守（1 ID 自东、58 ID 自南）。8.21 德军在红卫城前止步。

- 诺夫哥罗德：8.10 I 军（11、21 ID）与 XXVIII 军（121、122 ID）自希姆斯克进攻；8.11 占希姆斯克，48 A 防线崩溃；8.15–8.16 126 ID 第 424 团夺诺夫哥罗德克里姆林；8.19 首个沃尔霍夫河桥头；8.20 21 ID 占丘多沃，切断十月铁路；8.26 21 ID 抵格鲁济诺。
- 旧鲁萨：8.5 X 军（30、126、290 ID）向旧鲁萨推进，8.9 入城；8.12 苏 34 A 自旧鲁萨以南出击，突入约 40 km，8.14 切断旧鲁萨—德诺铁路，X 军几乎被围；8.19 LVI 军部（转移约 260 km）率 SS-T、3 ID(mot) 侧击 34 A；8.20 与 30 ID 会合；8.25 34 A 退过洛瓦季河，被俘 1.8 万余人。
- 留班—姆加—什利谢利堡（XXXIX 摩托化军，属 center）：8.25 20 ID(mot) 占留班；8.31 占姆加；9.7 占锡尼亚维诺；9.8 抵拉多加湖什利谢利堡，封锁圈合拢。8.29 18 ID(mot) 占基里希。
- 9.9 XLI 军自西、南两面进攻红卫城；9.10 1 PzD 切断红村—红卫城公路；9.11 1 PzD 占杜德霍夫高地，6 PzD 自西北合围红卫城；9.12 58 ID 占红村；9.13 红卫城失守；9.15 德军抵普尔科沃高地；9.18 装甲集群坦克支援 L 军攻占普希金（在列宁格勒的最后一次行动）；9.19 58 ID 抵乌里茨克电车终点。
- 奥拉宁鲍姆：9.8 XXXVIII 军（291、58、1 ID）在罗普沙附近进攻；9.15 291 ID 占罗普沙；9.16 1 ID 在斯特列利纳抵芬兰湾，奥拉宁鲍姆桥头堡形成；9.22–9.23 苏军放弃彼得霍夫。
- 指挥：9.5 伏罗希洛夫接替波波夫任列宁格勒方面军司令；9.11 晚任命朱可夫，9.13 抵达，9.14 就职（参谋长霍津、费久宁斯基）；9.16 费久宁斯基接替 F. S. 伊万诺夫任 42 A 司令。
- 第一次锡尼亚维诺战役（9.10 起）：54 A 286 SD 向姆加进攻被 12 PzD 击退；310、128 SD 向锡尼亚维诺推进 6–10 km；115 SD 与海军陆战第 4 旅渡涅瓦河，夺「涅瓦河小块地」。9.26 停止主动进攻。
- 杰米扬斯克：8.30 X 军（缺 126 ID）、3 ID(mot)、SS-T 向旧鲁萨东南进攻；9.1 II 军自霍尔姆进攻；9.8 占杰米扬斯克，27 A、11 A 与 34 A 各一部在洛瓦季河—波拉河间被围，被俘约 3.5 万人；30 ID 与 19 PzD（LVII 军，属 center）在莫尔沃季齐合围；9.24 123 ID 在奥斯塔什科夫西北接替 LVII 军，前线稳定于韦利耶湖—谢利格尔湖，为北方集团军群最东南的推进点。
