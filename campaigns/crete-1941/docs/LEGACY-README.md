# 1941 克里特岛战役 · 战旗推演

沿用波兰／法国版本的 TypeScript、Vite、D3/SVG、SDF 战线、Three.js 沙盘、复古作战室界面、字体、音乐、音效和模型资产。独立目录部署，不依赖原项目运行，也不修改原项目。地图覆盖克里特全岛及雅典、罗得岛、米洛斯和南部海域。

## 运行

```sh
npm install
npm run dev
```

开发地址 http://127.0.0.1:5195/ 。生产构建 `npm run build`，随后 `npm run preview`，地址 http://127.0.0.1:4195/ 。也可双击 `start.command`。网页需要 HTTP 服务，不能直接用 file:// 打开。

## 功能

- 1941-05-20 至 1941-06-01 连续时间轴和五阶段入口。
- 33 处地名、28 个部队单位、18 条行动路线、24 个事件、16 个控制区关键帧。
- 德、英、希、新西兰、澳大利亚与意大利部队；四个空降战区、马莱迈机场争夺、西部推进、南岸撤退、海军撤运。
- 部队树与搜索、单位详情／跟随、事件照片与史料、图层开关、导演模式、变速播放、全屏、2D／3D。
- 五段本地英语讲解与文稿，明确标注现代合成语音；六张克里特历史照片与一张 1953 年美国陆军战史地图。
- 本地海岸线、高程、核心及周边瓦片；所有运行资产离线可用，不调用远程瓦片。

操作：滚轮缩放，拖动平移；空格播放／暂停，方向键切换事件，H 回到全岛，M 切换二维／三维。

## 历史边界

地图为战役级教学重建，不是逐时实测阵地。空降／空运和海运使用虚线，地面控制仅在克里特岛掩膜内计算。部分事件只确知日期，卡片会标注时间精度。编制树含为阅读而设置的地区汇总节点；3D 士兵为既有简化模型，不代表考据制服。兵力口径不一致时保留空值，不强行相加。

详细依据：[docs/HISTORY.md](docs/HISTORY.md)。媒体与许可：[docs/MEDIA.md](docs/MEDIA.md)。任务规划：[docs/PLAN.md](docs/PLAN.md)。

## 验证与再生成

- `npm run verify`：类型检查、59 项测试、数据校验、生产构建。
- `npm run shots`：Chrome 实测（需先启动 4195 生产预览），截图和报告写入 `docs/qa/`。
- `python3 scripts/seed_campaign.py`：重建克里特数据（需要 Python 地理依赖）。
- `bash scripts/geo/run_all.sh`：重建真实地理资产，依赖见 `scripts/requirements.txt`；下载阶段需要联网。

完整验收结果见 [docs/IMPLEMENTATION.md](docs/IMPLEMENTATION.md)。
