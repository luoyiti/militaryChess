# 克里特岛战役交付记录

实现目录：`BattleOfCrete-1941`。以法国版完整复制为基线，保留原有离线资产、Vite/TypeScript、D3、SDF、Three.js、音频、界面与编排方式；复用同系列巴尔干版的克里特史料、媒体与周边地形覆盖实现。

## 完成内容

- 1941-05-20—06-01 连续时间轴、五阶段镜头入口、导演模式与变速播放。
- 33地名、28单位、18路线、24事件、16控制区帧、4孤立区域、7装备、11来源。
- 六方编组、四处空降、马莱迈转折、西部推进、穿越白山、北岸与南岸海撤、东部意军登陆。
- 真实克里特海岸与高程，核心170张瓦片、周边300张瓦片；二维与三维镜头边界约束。周边地理覆盖雅典、米洛斯、罗得岛与南部海域。
- 6张克里特档案照片、1张1953年战史地图、5段现代合成英语讲解（94.5秒），全部本地资源。
- 保留部队卡3D模型、部队树搜索、镜头跟随、图层、全屏与资料面板。

## 验证

- `npm run verify`：类型检查、59项测试、数据校验、生产构建通过。
- 数据校验0错误、1提示：第5山地师的东进轨迹为先头分遣队作战重心，约60km/日的速度超过普通步兵阈值；详见 `HISTORY.md`。不是全师行军实测。
- `scripts/qa-crete.mjs`：20个检查状态，包括全岛、首日空降、马莱迈、撤退、结束、3440宽屏、最小缩放、四方向边缘、3D与返回、事件卡、部队卡、图层、英语音频、史料、390手机与手机事件卡。所有检查零页面错误、零资源失败、零镜头覆盖越界、零横向溢出。浏览器屏蔽所有外网请求后完成，证明运行资产可离线使用（仍需本地HTTP服务）。
- `scripts/qa-playback.mjs`：从真实开场按钮进入，导演模式触发“水星行动”事件，8倍播放到6月1日23:59并停止；手机展开侧栏、切换撤退章节、收起侧栏成功，零页面错误。
- `public/geo/context.verify.json`：300张周边瓦片均可解码、尺寸正确，投影误差小于5.9e-11；核心原始地理资产在周边生成前后保持一致。
- `docs/qa/reference-integrity.json`：波兰、法国参考目录7385个文件哈希逐一相同，无修改。

实际截图及原始结果保存在 `docs/qa/`。测试使用本机Chrome与软件WebGL，验证功能和画面，不作为硬件GPU帧率基准。
