# 史料与可视化口径

地图以1940-10-28历史国界为背景，战况按关键节点重建；控制区与国家疆界分开。插值只描述阶段变化，不代表每日精确阵地线。

- 希意战争使用希腊陆军品都斯、科尔察、希马拉和春季攻势资料；后期以美国陆军DA Pam20-260、澳大利亚官方史及新西兰官方史交叉核对。
- 南斯拉夫4/17签署、4/18中午生效分成事件；希腊东马其顿和西部主力投降分开，英联邦撤离继续呈现。
- 克里特5/20登陆前保持无轴心控制。雷西姆诺机场被隔离守军保留至5/30投降，伊拉克利翁海撤和南岸最后撤离分别记载。
- 各国编制分树；军团/师的地图位置是指挥或作战重心。军团及其师不重复相加为兵力。资料不详的数字显示“未详”。
- 数据校验唯一速度提示为第5山地师5/29—30北岸追击分遣队的作战重心变更，约60km/日。该轨迹明确为分散作战重心，并非全师徒步里程；保留提示而未提高所有山地步兵的速度上限。
- 森林、湿地、部分历史边界数字化为有来源的战役级近似；具体记录在public/geo/balkans1940.meta.json与geo_pipeline.meta.json。
- 照片均保留真实年代、作者、许可和原链接；界面配乐不是巴尔干同期战场录音。英语档案以同期NFU原片外链提供。
