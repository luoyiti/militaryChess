# 克里特岛战役实施计划

范围：1941-05-20 至 1941-06-01，独立 BattleOfCrete-1941。法国版完整复制作为基础，波兰与法国只读；保留引擎、界面、资产、时间轴、导演模式、3D、音效和来源面板。

1. 记录源目录文件哈希，复制工程及全部资产。
2. 并行制作克里特真实地理地图和史料支持的事件、部队、路线与控制区数据。地图覆盖全岛并扩展周边，限制镜头边界。
3. 整合六方部队、五阶段导航、历史说明和可选英文旁白。空降、补给和海上撤离不是领土控制。
4. 类型检查、历史数据校验、单元测试和生产构建；浏览器检查关键日期、全景、宽屏、手机、缩放和平移边界、3D、图层、事件/部队卡、音频与离线。
5. 复核源目录哈希并记录交付地址、运行方式和已知近似。
