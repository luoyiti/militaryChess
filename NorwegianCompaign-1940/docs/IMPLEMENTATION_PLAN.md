# 挪威战役实施计划

**目标**：在 `NorwegianCompaign-1940/` 独立运行 1940-04-09 至 1940-06-10 的动态战役地图，保留波兰项目的引擎与作战室设计。
**执行**：主 Agent 集成、开发、验证；一个研究 Agent 独立核实历史。用户已授权计划后直接实施，省略逐项审批与重复审查。
**技术**：原版 TypeScript / Vite、D3、Canvas + SVG、Web Worker SDF、Three.js、howler / Web Audio；不引入另一套地图或动画引擎。
**需求依据**：本次用户任务；核心史料见 `research/HISTORY.md` 和 `src/data/sources/`。

依赖顺序：`frame → 地理矢量/高程/瓦片/掩膜`；`schema + gazetteer + sources → units/routes/events/fronts → db → 原地图/时间轴/导演/沙盘`。

## 2. 历史与素材组织

- `src/data/gazetteer/`：港口、机场、山谷、海战概略海域；`oob/` 与 `routes/` 按国家独立存储。
- `events.json`：约 30 个核实节点；4/9 多港口入侵、Blücher；4/10 与 4/13 纳尔维克海战；中部登陆、山谷抵抗与 5/2–3 撤离；5/13 比耶克维克、5/28 纳尔维克、6/4–8 撤运、6/8 Glorious、6/10 停战。
- `fronts/`：分散港口/山谷控制示意区；北部盟军控制用 AL 合并场，棋子仍按 NO / UK / FR / PL 区分。中立瑞典保持独立。海面不涂作陆上占领区。
- Route 增加 `kind=land/naval/landing/air/evacuation`，继续使用原 `routeProgress`；线型与符号区分。所有端点间插值皆为解释行动方向，不是 GPS 航迹。
- 日期确证、时分不确证时 `timePrecision=day`，界面显示“当日（编排时刻）”；已核实的 Blücher 等时间仍保留时分。
- `sources/` 存史料与地理来源；`research/HISTORY.md` 保存日期核对与简化说明；事件卡和资料页直接可查来源。
- 本地 `public/` 独立包含地图、字体、通用音效与获许可的挪威照片；逐项许可在 `credits.json` / `LICENSES.md`。没有照片或朗读声音时地图仍正常。

## 4. 基础版本交付标准

- 首屏完整显示挪威及相关海域；全国与局部切换可用，滚轮/拖动顺畅；离线地图不调用在线瓦片。
- 1940-04-09～06-10 播放、暂停、拖动、0.5–8×、前后事件和指定日期跳转可用；事件卡、标记、部队、控制场时间一致。
- 五国单位与海陆空行动清晰区分；纳尔维克与中部战区并行展示，避免一条贯穿挪威的虚构连续前线。
- 重要史实日期与来源可查；控制区/航线、聚合单位、示意模型等明确标注解释性简化。
- 浏览器无相关 console error、无缺失资源；桌面与窄屏截图目检，打开档案、图例、音效及 3D；运行按日期遍历的自动化验收。
- 原项目源码与资产哈希不变；新项目源码/构建产物无对原目录的运行时引用。
